Variable!


JavaScript mein variable aik container ( box / dabba )hota hai jo data ko temporarily store/save karta hai.


JavaScript code run hota hai 2 steps mein:

Step 1 : Memory Allocation ( Creation Phase )
Step 2 : Code Execution


Step 1 :

JavaScript pehlay variables ko scan karta hai.
Var ko undefined assign kar deta hai.
functions ko completely load karta hai memory mein.

Step 2:
Actual values assign hoti hain.
Execution top to bottom hota hai.


Hoisting : Javascript mein var variables hoist ho jaate hain.
